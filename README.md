# Подземелье Аида: Побег

Кликер/idle-RPG в стиле греческой мифологии для платформы «Яндекс Игры».
Чистые HTML5 + CSS3 + JavaScript, без сборки: `index.html`, `style.css`, `game.js`.

## Запуск локально
Откройте `index.html` в браузере или поднимите сервер:

```
python -m http.server 8000
```

Вне Яндекса SDK не загрузится — игра сохраняется в `localStorage`, реклама выдаёт награды сразу.

## Консоль разработчика
Открывается клавишей `` ` `` или F2 (на телефоне — 5 касаний по названию локации).
Доступна локально и по ссылке с `?dev=1`. Команды помечают сохранение как читерское,
рекорды после этого не уходят в лидерборд. Команда `help` — список команд.
Для релиза в `game.js` поставьте `DEV_ALLOWED=false` (сборка на GitHub делает это сама).

## Тесты
```
node tests/run.js
```
Проверяют механики и баланс на заглушке браузера (Node 18+).

## Языки
Русский и английский. Язык выбирается сам: параметр `?lang=ru|en`, затем язык из SDK площадки, затем браузера
(русский для ru/be/uk/kk, иначе английский). Игрок может сменить его в настройках ⚙️.

## Площадки
Код один, сборки две — `bash build.sh` кладёт в `build/`:
- `yandex-games.zip` — с SDK Яндекс Игр;
- `crazygames.zip` — с SDK CrazyGames v3, английский заголовок страницы.

На CrazyGames игра сама включает: их рекламу (видео за награду и межуровневую, с паузой и без звука во время ролика),
облачные сохранения (модуль Data), события загрузки и начала игры, кнопку выключения звука площадки, happytime
после боссов актов. Кнопки рекламы там перенесены с экрана боя во вкладку «Награды»; если реклама отключена
(Basic Launch) или стоит блокировщик, они неактивны с пояснением. Лидерборд и покупки Нектара скрыты — у CrazyGames
это функции по приглашению.

Проверка на CrazyGames: при загрузке архива включите Progress Save, затем откройте их Preview tool.
Локально SDK работает в режиме `local` на `localhost` (вместо рекламы — заглушка).

На широком экране (ПК, 16:9, мобильный 800×450) интерфейс раскладывается в две колонки.

## Звук
Весь звук синтезируется на лету через Web Audio, аудиофайлов нет. Блок «ЗВУК» в конце `game.js`.
- Музыка: тихий эмбиент 66 уд/мин — гул-аккорд и редкая мелодия «лиры» с паузами и реверберацией.
  У каждого акта свой лад и тоника (`MODES`), мотивы мелодии — `MOTIFS`, их порядок — `MPAT` (`-1` — такт тишины).
  В бою с боссом добавляется «сердцебиение».
- Эффекты: `sfx('click'|'crit'|'kill'|'boss'|'buy'|'lose'|'reward'|'bossIn'|'fairy'|'skill')`.
  Минимальный интервал между одинаковыми звуками — `SFXGAP`, чтобы частые клики и убийства не шумели.
- Громкость эффектов и музыки — ползунки в настройках ⚙️. Звук включается после первого касания (требование браузеров),
  замолкает на время рекламы и в свёрнутой вкладке, подчиняется кнопке выключения звука CrazyGames.

## Публикация
- **Яндекс Игры:** загрузите архив с `index.html`, `style.css`, `game.js` в корне. Готовый
  архив с выключенной консолью лежит в артефактах запуска *Actions → Тесты и публикация → yandex-games* (для CrazyGames — *crazygames*).
  В консоли разработчика Яндекса создайте лидерборд `floors`.
- **GitHub Pages (демо):** Settings → Pages → Source: **GitHub Actions**. После каждого пуша в `main`
  сайт обновляется сам.

## Как залить на GitHub
1. На github.com создайте **пустой** репозиторий (без README и лицензии).
2. Запустите `push-to-github.bat`, вставьте адрес репозитория. При запросе войдите в браузере.

Вручную:
```
git init
git branch -M main
git add -A
git commit -m "Первый коммит"
git remote add origin https://github.com/ИМЯ/РЕПО.git
git push -u origin main
```
