## 2. Оформление

- **Обложка:** Управление → Оформление → Обложка → загрузить `cover_1920x768.jpg`.
- **Аватар:** нажмите на аватар → загрузить `avatar_400.png`. Миниатюру выделите кругом по лицу Аида.
- **Кнопка действия** (если есть в «Управлении»): тип «Открыть приложение» или ссылка → `https://vk.ru/app54840781`, текст «Играть».

## 7. Связать сообщество с игрой

1. dev.vk.com → ваша игра → Настройки → Информация → **Официальное сообщество** → выбрать «Подземелье Аида: Побег» → Сохранить.
2. В самой игре в настройках (шестерёнка) теперь есть кнопка **«Поддержка»**: она ведёт в это сообщество. Это требование каталога VK. Появится после `push-to-github.bat`.
