# Подземелье Аида: Побег — публикация в «Играх ВКонтакте»

Это пошаговая инструкция: регистрация игры, загрузка, оформление и подача в каталог.
Названия разделов и ссылки взяты из документации VK для разработчиков (dev.vk.ru) на октябрь 2026. Интерфейс может немного отличаться.

## 0. Что уже готово

| Что | Где |
|---|---|
| Сборка для ВКонтакте с VK Bridge, облачными сохранениями и рекламой VK | `build/vk-games.zip` и папка `dist/vk` (её же GitHub Pages публикует по адресу `/vk/`) |
| Иконка 576×576 (универсальная) | `store/vk/icon_576.png` |
| Иконка 278×278 (каталог) и 150×150 (маленькая) | `store/vk/icon_278.png`, `store/vk/icon_150.png` |

| Большой сниппет 1120×630 | `store/vk/snippet_1120x630.jpg` |

Что игра делает в VK:
- Сразу после запуска отправляет `VKWebAppInit`.
- Сохраняет прогресс в облако VK (`VKWebAppStorageSet`), поэтому он переносится между телефоном и компьютером. Копия также хранится в браузере.
- Показывает рекламу за вознаграждение (Гермес, Сундук Харона, x2 офлайн-дохода, спасение от босса).
- Показывает межстраничную рекламу, но не в первые 3 минуты и не чаще раза в 4 минуты. Ранняя реклама — частая причина отказа модерации.
- Ставит игру на паузу и выключает звук на время рекламы. Звук также выключается, когда игра свёрнута.
- Берёт язык из параметра VK `vk_language`. По умолчанию язык русский.
- Добавляет в настройки кнопку «Рассказать друзьям» (`VKWebAppShare`).
- Скрывает покупки Нектара за деньги и лидерборд Яндекса.

## 1. Где будет лежать игра — GitHub Pages (рекомендуется)

На бесплатном хостинге VK нельзя размещать аудиофайлы: в документации сказано «Размещать аудио- и видеофайлы на хостинге нельзя». В игре есть музыка и звуки, поэтому она будет открываться с вашего GitHub Pages. Там уже публикуется версия для Яндекса.

1. Запустите `push-to-github.bat`. Скрипт отправит код в репозиторий `github.com/Sacredz58/Idle-cliker`.
2. На GitHub откройте репозиторий, затем **Settings → Pages**. В поле **Source** выберите **GitHub Actions**, если это ещё не выбрано.
3. Откройте вкладку **Actions** и дождитесь, когда запуск «Тесты и публикация» станет зелёным. Это займёт 1–2 минуты.
4. Проверьте в браузере, что открывается
   `https://sacredz58.github.io/Idle-cliker/vk/index.html`
   Вне VK игра запустится в обычном режиме, это нормально. Если адрес не открывается, посмотрите точный адрес в **Settings → Pages**. К нему нужно добавить `vk/index.html`.

> GitHub Pages отдаёт файлы по HTTPS и не присылает заголовок `X-Frame-Options`. Именно это нужно VK, чтобы игра открылась в окне (iframe).
> После каждого `push-to-github.bat` версия в VK обновляется сама.

Другой вариант — любой платный хостинг с HTTPS. Залейте туда содержимое `build/vk-games.zip` и укажите его адрес в шаге 3.

## 2. Регистрация игры

Понадобятся аккаунт ВКонтакте и мобильное приложение VK на телефоне для подтверждения.

1. Войдите на **vk.com** с компьютера.
2. Откройте **dev.vk.com** и нажмите **Создать приложение** в верхнем меню. Список ваших игр — **Приложения** (`https://dev.vk.com/ru/admin/apps-list`). Если dev.vk.com пишет «Страница не найдена», значит вы не вошли в аккаунт: войдите на vk.com в этом же браузере и обновите страницу.
3. В меню слева нажмите **Создать приложение**.
4. В поле **Тип** выберите **Игра**. Название — **Подземелье Аида: Побег**. Жанр — ближайший к кликеру/RPG. Нажмите **Создать**.
5. Подтвердите действие в мобильном приложении VK. Push-уведомление придёт, только если приложение запущено на телефоне.
6. Запишите **ID игры**: откроется панель управления, ID будет в её адресе и в настройках.

## 3. Размещение (обязательно, без этого игра не запустится)

В настройках игры откройте **Размещение**.

1. Вставьте во все три поля — **Web**, **Мобильная версия сайта** и **Мобильное приложение** — один и тот же адрес:
   `https://sacredz58.github.io/Idle-cliker/vk/index.html`
2. Пока не меняйте поле **Состояние для пользователей** (значение «Отключено»). Игра видна только вам и администраторам.
3. Откройте `https://vk.com/app<ID>` и проверьте:
   - игра загружается, музыка играет после первого нажатия;
   - сохранение работает: поиграйте, закройте игру и откройте снова — этаж и золото на месте;
   - игра открывается и с телефона в приложении VK.
4. В разделе **Отображение** выберите самый большой размер окна. Игра подстраивается под любой размер, и в широком окне она раскладывается в три колонки.

## 4. Информация и оформление

**Информация** — описание игры:

> **Подземелье Аида: Побег** — idle-кликер с элементами RPG по мотивам греческих мифов. Вы начинаете на самом дне Тартара: бьёте монстров, призываете богов сражаться за вас и поднимаетесь этаж за этажом через шесть миров — Тартар, Асфодель, Элизиум, Олимп, Вход в Хаос и Сердце Хаоса.
>
> На каждом 10-м этаже ждёт босс с таймером: Эринии, Лернейская Гидра, Минотавр, Ахилл, Владыка Аид и многие другие. Побеждайте их, забирайте добычу и поднимайтесь дальше — боги сражаются даже без вас.
>
> • 17 легендарных видов оружия и 18 богов с особыми силами
> • 4 активных умения
> • Вещи 8 редкостей, одинаковые объединяются в более сильные
> • Перерождение за души и вечные дары
> • Постройки с вечными бонусами: Кузница Гефеста, Сад Персефоны, Библиотека Афины
> • Задания дня, награды за вход и 24 подвига
> • Доход, пока вас нет в игре

**Оформление** — какие файлы загрузить в какое поле:

| Вкладка → поле | Файл |
|---|---|
| Иконки → Универсальная иконка 576×576 | `icon_576.png` |
| Иконки → Иконка для каталога и сниппетов 278×278 | `icon_278.png` (менять можно не чаще 2 раз в 2 недели) |
| Иконки → Маленькая иконка 150×150 | `icon_150.png` |
| Иконки → Фавикон 32×32 | `favicon_32.png` |
| Изображения → Большой сниппет 1120×630 | `snippet_1120x630.jpg` |
| Изображения → Скриншоты, ориентация **Альбомная** (1200×600) | `land_1_battle.png`, `land_2_boss.png`, `land_3_items.png`, `land_4_house.png` |
| Видео → Промовидео (до 30 с) | `promo_ru_1920x1080.mp4` |
| Видео → Видео для блока «Рекомендуемые сегодня» | тот же `promo_ru_1920x1080.mp4` |
| Экран запуска → Цвет фона за иконкой | `#0E0908` (цвет фона игры); анимированную иконку не загружаем, переключатель «Анимация иконки» оставить выключенным |

Скриншоты показываются на экране запуска в версии для компьютера, поэтому выбрана альбомная ориентация. Если переключить ориентацию на «Книжную», VK удалит уже загруженные скриншоты. Для книжной есть `screen_1_battle.png` … `screen_5_house.png` (600×1200).
Видео можно обновлять не чаще 2 раз в 2 недели, поэтому загружайте финальную версию.

## 5. Поддержка (требование каталога) — ✅

Сообщество: https://vk.ru/club242475048. В игре в настройках есть кнопка «Поддержка», она ведёт туда (`VK_SUPPORT` в `game.js`).
Как заполнить сообщество — тексты, обложка и аватар: `store/vk/community/COMMUNITY.md`.

## 6. Реклама (монетизация)

Реклама в сборке включена. Пока монетизация в VK не подключена или ролики не загрузились, кнопки «за видео» показывают «Сейчас нет рекламы, попробуйте позже», и игра продолжается.
- Монетизацию подключают в настройках игры, в разделе про рекламу и монетизацию.
- Чтобы до подключения убрать кнопки «за видео» совсем, соберите игру командой `VK_ADS=0 bash build.sh`. Для версии на GitHub Pages нужно поменять в `game.js` строку `const VK_ADS=true` на `false` и сделать push.

## 7. Модерация и выход в каталог

Проверьте пункты, которые VK требует для каталога:

| Требование | Статус |
|---|---|
| Работает без ошибок на выбранных платформах | проверьте сами в шаге 3 (компьютер и телефон) |
| Звук можно выключить | ✅ кнопка звука и ползунки в настройках |
| Обучение с подсказками | ✅ |
| Основной язык — русский | ✅ |
| Канал поддержки | ⏳ шаг 5 |
| Нет рекламы сразу после запуска | ✅ первые 3 минуты рекламы нет |
| Внутриигровую валюту не продают за деньги в обход голосов VK | ✅ покупки Нектара в VK отключены |
| Уникальное название и качественная графика | ✅ (проверьте поиском в каталоге, нет ли игры с таким же названием) |
| Личные данные не публикуются без спроса | ✅ «Рассказать друзьям» открывает стандартное окно VK |

Подача заявки:
1. В настройках игры откройте **Модерация**.
2. Выберите платформы: **Мобильная** и **Web**. Площадка — **ВКонтакте** (Одноклассники можно добавить позже).
3. В описании для модератора напишите: «Idle-кликер. Нажимайте на монстра, покупайте оружие и богов, на каждом 10-м этаже — босс на время. Обучение подсказками в начале, кнопка „?“ — справка по всем механикам».
4. Нажмите **Пройти модерацию**. Статус сменится на «Проверка».
5. Проверка обычно занимает 2–7 рабочих дней. Если будет отказ, замечания придут в «Чат с модератором». Пришлите их мне, исправим и подадим заново.
6. После одобрения переведите **Состояние** в **Включено**. Игра появится в каталоге с плашкой «Новое».

## Если что-то не работает

- **Белый экран в VK.** Проверьте, что адрес из шага 3 открывается в обычном браузере и что запуск в Actions зелёный.
- **Нет сохранений.** VK хранит облачные сохранения год. Прогресс из Яндекс Игр в VK не переносится: это разные площадки.
- **Вопросы к VK.** В настройках игры: **Помощь → Написать в Поддержку**.
